#Personal Portfolio 
A responsive personal portfolio website for Ayezah Arshad, a BS Computer Science student and aspiring web developer. The portfolio presents personal information, technical skills, projects, education, web-development practice, and contact details.
This portfolio is designed to provide a professional online presence and showcase web-development skills and academic work.

#Features:
Home / Hero section
About Me
Skills
Featured Projects
Education & Certificates
Web Development Practice
Contact section
Social media links
Responsive navigation
Contact form with basic validation and success feedback
